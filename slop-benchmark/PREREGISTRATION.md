# Pre-registration — Does structural admission gate AI slop?

**Locked before any run.** Edits after the first `run.py` invocation are tracked in git; the
window-close ref of this file is the registered hypothesis set (cf. the paper's own endorsement
of pre-registration, ref [11]).

## Question

Does CANONIC's structural-admission gate (the three axioms + the three claim gates) actually
keep AI slop out of a corpus, and at what cost to legitimate content? Restated as detection: the
gate is a binary classifier (ACCEPT/REJECT); we measure it against baselines and ablate which
gate carries the load.

## The independence that makes it credible

The paper's §3 names the fatal weakness: producer = validator = evidence = the same party. We
break that here by **cross-provider separation**:

- The validator is implemented from the **published spec only** (Appendix A + Algorithm 1 + §3
  claim gates) — no hidden behavior.
- The adversarial content (C3) is generated by a **different model family** than any used to
  author the framework (DeepSeek / OpenAI / Anthropic, rotated), blind to the validator internals.
- Ground-truth slop/legit labels come from a **3-provider panel majority vote on the prose only**
  (structure hidden), so labels are independent of the gate. We report Fleiss' κ.

## Design

Unit = one candidate corpus item, packaged as a governed scope (a directory). Ground truth is a
property of the **content**; the gate decision is a property of the **structure**. The experiment
measures how well structure predicts truth.

| Class | Content (ground truth) | Structure | Gate *should* | Gate *will* (predicted) |
|------|------------------------|-----------|---------------|--------------------------|
| C1 legitimate + scaffolded   | legit | valid triad, defined terms, real in-window commit | ACCEPT | ACCEPT ✓ |
| C2 naive slop                | slop  | no triad / undefined terms / no commit            | REJECT | REJECT ✓ |
| C3 **adversarial slop**      | slop  | full triad, circular VOCAB, real-but-irrelevant commit, self-chosen window | REJECT | **ACCEPT ✗** |
| C4 legitimate, unscaffolded  | legit | plain prose, no triad                             | ACCEPT | **REJECT ✗** |

## Arms (baselines + ablation)

- **B0** admit-all (reference floor)
- **B1** off-the-shelf AI-text detector (measures Table 1 row 1 instead of asserting it)
- **B2** LLM-as-judge content-quality filter (the "human review" proxy)
- **T**  CANONIC three-gate validator
- **Ablations:** T−Introspection, T−Evidence, T−Scope (which gate does the work)

## Metrics

Positive class = slop (the thing we want to REJECT). Per arm: confusion matrix vs ground truth,
precision / recall / F1, accuracy. Plus three headline numbers the paper currently lacks:

1. **The gap:** `reject_rate(C2)` − `reject_rate(C3)`. Predicted large (≈0.9). This converts the
   prose claim "raises the cost of unaccountable content, not of accountable falsehood" into a number.
2. **The tax:** `reject_rate(C4)` = legitimate content the gate wrongly excludes.
3. **Complementarity:** does B2 (semantic) catch the C3 that T (structural) misses? If yes, the
   honest conclusion is *structural ∥ semantic — ship both*, not *structure solves slop*.

## Pre-registered predictions (commit these now; grade them after)

- P1: T rejects ≥ 0.85 of C2 and ≤ 0.20 of C3 → gap ≥ 0.65. **(falsifies B.3's "structurally inadmissible")**
- P2: T wrongly rejects ≥ 0.80 of C4 (the structure tax is real and large).
- P3: B2 (content judge) rejects more C3 than T does (semantic beats structural on dressed slop).
- P4: No single arm dominates on all four classes → the paper's strong claim must weaken to a complementarity claim.
- Falsification: if T rejects C3 at the same rate as C2, the §3 adversarial argument is wrong and CANONIC is stronger than the author claimed.

## Out of scope (honesty bounds)

n is small in the pilot (~40); the full run targets 400–600. Cross-provider ≠ human adversary —
it is a *model-independence* proxy, not a *human red-team*. We report both bounds, never round them away.
